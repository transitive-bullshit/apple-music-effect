# Project: apple-music-effect

A real-time, physically based recreation of the liquid logo animation from Apple Music's "Made by Sound" identity (Oct 2026): a WebGL2 oil-and-glass simulation with a player (custom logos, MP4 export), an explainer, and a headless renderer. See `contributing.md` for setup and commands.

## Conventions

- use `pnpm`
- use modern TypeScript (ESM only, no CommonJS)
- no semicolons; oxfmt formats (`pnpm fix:format`) and oxlint lints (`pnpm fix:lint`)
- `pnpm test` runs format, lint, types, and unit tests; keep it green
- use `ky` as a wrapper around `fetch` for HTTP requests
- use `zod` to validate external data
- for local development, use `pnpm dev` and the Portless URL it prints (apps only)
- use `uv` for the Python analysis (`analysis/`)

## Mental model

The film (`src/scene.ts`) is two shots, icon then wordmark, each a set of keyframes measured off Apple's film plus parameters → the engine (`src/engine.ts`) steps a shallow-water oil simulation from rest at each shot's start and renders each pixel by spectral ray tracing through the surface (`src/shaders.ts`): the analytic dome (the rig's lens of oil, its shape per frame fitted to refraction measured in the film: `analysis/capture.py` → `data/fit/`), the simulated oil, the glass tile, the reveal → one page in two modes: the player (`index.html`) and render mode (`?mode=render`, driven by `scripts/render.ts`). `scripts/compare.ts` sets renders beside the reference film; `docs/effect-analysis.md` records what the film shows, the physics, and how each value was matched.

## Rules

- Frames are pure functions of time: no `Math.random()` or wall-clock time in the engine; seed anything random. The player, stills, renders and exports must agree.
- Measure before tuning: the film times are reel times (YouTube = reel + 69.334 s); placements are in world units (1 unit = 540 px at 1080p). Check changes with `pnpm compare`, by eye; `pnpm score` (RMS error) prefers soft, dark frames, so it only brackets.
- The sting audio is the master: never edit or re-time it.
- `data/timeline.json` is generated by `analysis/timeline.py`; its shape is a contract with `src/timeline.ts`.
- `data/fit/*.json` is generated by `analysis/capture.py`, whose dome model (`lens_z`, `refracted`) mirrors `lensZ` and the optics in `src/shaders.ts`: change them together, and refit (`--fit`) rather than editing the files.

## Not in git

- `reference/` (Apple's film, reel and logos, including our traces) and `media/` (the sting): copyrighted and trademarked, never committed. Without them everything falls back to the demo brand in `public/demo/` and plays silent.
- `frames/`, `renders/`, `dist/`, `analysis/out/` (the capture's registrations): regenerable output.
- `readme.md` is marketing; technical docs go in `contributing.md`.

## Checks

`pnpm test` and `uv run pytest -q`; CI also runs `pnpm build` and `py_compile`, offline. `uv sync` prunes `.venv` to the groups you name, so run the analysis with `uv run --group analysis`.
